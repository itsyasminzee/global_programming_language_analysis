# Global Programming Language Analysis (2020–2026)

## Project Overview
An end-to-end data analytics project exploring programming language popularity, learning difficulty, specialization, career opportunities, salary trends, and market demand from 2020 to 2026.

## Objectives
- Analyze programming language popularity and developer activity over time.
- Compare learning difficulty, specialization, and technology use cases.
- Evaluate salary trends and market demand to identify career opportunities.
- Transform raw data into actionable insights through interactive dashboards.

## Tools & Technologies
- **Python:** Exploratory Data Analysis (EDA) and data exploration
- **Power Query:** Data cleaning, transformation, and preparation
- **Power BI:** Interactive dashboard development and data visualization
- **DAX:** Measures, calculations, and analytical metrics

## Project Workflow
1. **Data Exploration:** Examine dataset structure, distributions, and trends using Python.
2. **Data Cleaning:** Handle inconsistencies, standardize categories, and prepare data using Power Query.
3. **Data Modeling & Analysis:** Develop measures and analytical calculations using DAX.
4. **Visualization:** Build interactive Power BI dashboards to explore programming language trends and opportunities.
5. **Insights & Recommendations:** Interpret findings to highlight relevant technology trends and career opportunities.

## Dashboard Highlights
- **Market & Popularity:** Programming language rankings, popularity trends, and developer activity.
- **Technology Landscape:** Language paradigms, specializations, and application domains.
- **Career & Opportunity:** Salary comparisons, learning difficulty, and market demand.

## Key Takeaways
The analysis provides a comparative view of programming languages across popularity, technical specialization, learning difficulty, compensation, and demand. It helps developers and aspiring tech professionals explore technology trends and make more informed learning and career decisions.

## Repository Contents
- `global_programming_languages_dataset_2020_2026.csv` – Dataset used for analysis
- `EDA_GPL.ipynb` – Python notebook for exploratory data analysis
- Power BI report (`.pbix`) – Interactive dashboards and visualizations, if included

## Disclaimer
The findings are based on the dataset used in this project. Salary, popularity, and demand figures should be interpreted within the dataset's assumptions and limitations and may not represent actual market conditions.
